取引ルールの見直し

現行損切り-6% / +20%で半分・+40%で残り / 25日 / 10銘柄 推奨損切り-8% / +20%で半分・+40%で残り / 40日 / 10銘柄 探索1位損切り-15% / +10%で全部 / 40日 / 10銘柄
探索 2023-01-13 〜 2025-07-30 検証 2025-10-30 〜 2026-10-30 組み合わせ 325 銘柄 3,680

結論

推奨は 損切り -8% / +20%で半分・+40%で残り / 40営業日 / 10銘柄 です。現行ルールからの変更は、損切りを -6% から -8% に、保有を 25日から 40日に延ばす2点だけです。先読みのない5つの条件とランダムの平均で比べると、直近1年は現行 +8.4% (最大DD -15.6%) に対し +16.9% (DD -12.0%) でした。約4年の通しでも +24.1% (DD -31.4%) から +49.0% (DD -23.1%) に改善しています。PF も、どの条件でも上がりました。

  • はっきりしているのは保有日数と損切り幅: 探索期間 (2023-01〜2025-07) では、どの損切り幅でも40日保有が一番良い結果でした。10〜15日保有はほぼ0%で、損切り -4〜-6% は -8% 以上より悪くなっています。現行の -6% では約半分の取引が損切りで終わっており、反発前に振るい落とされる取引が多い形です。利確の水準による差はこれより小さく、現行の +20%/+40% のままで問題ありません。
  • 探索1位は損切り -15% / +10%で全部 / 40日でした。ただ、1回の損失が資産の1.5% (1枠1/10 × 15%) になります。直近1年の平均も +10.1% で、-8% 案の +16.9% より低い結果でした。傾向 (40日・損切り広め) だけを取り入れ、-8% にとどめるのが実用的と判断しました。-8% 案は探索期間で325通り中33位で、まわりの値でも大きく崩れていません。ただし、最終的に -8% を選ぶ段階では直近1年の結果も見ているので、その分は割り引いてください。
  • タブごとには差がある: 高値ブレイク (直近1年 -2% → +35%) と MACD・RSI (+13% → +28%) は大きく良くなりました。一方で SCORE勢いは +17.3% → +14.5% と少し下がり、最大DD は -17.2% → -11.7% と小さくなりました。通しでは +82% → +60% です。乖離リバウンドは直近1年で下がりましたが、通しでは -22% → +26% と大きく改善しました。
  • 同時保有は10銘柄のままで良い: 8〜10銘柄が探索・検証とも最も良く、5銘柄にすると成績が落ちます。
  • 日経平均にはまだ届かない: 直近1年の日経平均は +23.3%、通しは +142% です。ルールの見直しでランダム買いも +14% → +24% に上がりました。改善の多くはルール自体の効果で、条件の選び方による上乗せは小さいままです。

まとめると、損切り -8%・40日保有に変えると、ほとんどの条件で PF とドローダウンが改善します。サイトのルール表示や決算回避の期間 (25日→40日) を変える場合は、言っていただければ反映します。

前提と注意点

共通の条件

シグナル翌営業日の寄り付きで買い、決算 (推定日) が保有予定期間に入る銘柄は買いません。利確・損切りの価格に場中で届いたらその価格、寄り付きで越えていたら始値で約定し、同じ日に両方に届いた場合は損切りを先とみなします。

売買コスト

手数料0円、スプレッドとスリッページは売買代金に応じて片道0.10〜0.40%。税引き前です。

ランダム

売買代金1億円以上の銘柄から無作為に買う形を3回試した平均です。どの条件にも使えるルールかを見るため、選ぶ対象に入れています。

データ

Yahoo Finance の日足 (調整済み)。現在上場している銘柄のみで、上場廃止銘柄は含みません。財務は現在値のため、×のタブは実際より良く出やすいです。
