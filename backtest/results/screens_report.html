結論

株価と出来高だけで判定でき、先読みの心配がないタブのうち、日経平均に勝ったものはありませんでした。直近1年の日経平均は +26.0% (最大DD -15.1%) でした。これに対し、一番良かった SCORE勢い は +18.4%、高値ブレイクは +6.8%、出来高急増は -35.1% です。日経平均を上回ったのは、成長株 +106.8%、SCORE業績 +55.1%、乖離リバウンド +40.0%、高配当 +31.6%、25日線押し目 +27.2% でした。ただし、どれも財務の現在値を過去に当てはめたタブで、実際より良く出ています。

  • 財務条件を外すと成績が消える: 乖離リバウンドは、財務条件付きなら +40.0% ですが、株価条件だけにすると +1.1% まで下がります。25日線押し目も、+27.2% から -0.9% になりました。財務フィルタが効いているように見える分は、ほとんどが「今の決算が良い銘柄を過去に選んだ」先読みによるものと考えられます。
  • 約4年の通し期間でも同じ傾向: 日経平均は +147.6% (年率 +27.0%) でした。これを上回ったのは、SCORE業績 +278%、高配当 +202%、成長株 +164% の財務タブだけです。株価だけで判定できるタブは、SCORE勢いの +82% が最高でした。株価条件だけにしたMACD・RSI (+99%) と25日線押し目 (+37%) も届いていません。
  • ランダムには勝つものと負けるものがある: 売買代金1億円以上の銘柄から無作為に買った場合、直近1年 +10.0%、通し +29.8% でした。SCORE勢いは両方の期間でこれを上回っています。一方、高値ブレイク (通し -37%) と出来高急増 (通し -63%、最大DD -67%) はランダムより明確に悪く、このルールでは使わない方が良い結果でした。
  • 新しいタブ: MACD・RSIは、直近1年が -1.0% (株価条件だけなら +6.3%) で、ランダム並みでした。好業績押し目は -13.3%、信用過多押し目 (信用倍率の条件なし) は -11.6% で、直近1年はどちらもマイナスです。好業績押し目は財務の先読みがあるのにマイナスなので、条件の組み方に問題がある可能性があります。
  • 決算回避ははっきりした効果なし: 回避すると成績が良くなったのは、25日線押し目・乖離リバウンド・好業績押し目でした。逆に悪くなったのは、割安PER・高配当・MACD・RSIです。決算日は推定日なので、この結果は参考程度です。

まとめると、このルール (損切り -6% / +20%で半分 / +40%で残り / 25営業日) でサイトのタブをそのまま使っても、日経平均を買って持つ方が成績が良かった、というのが正直な結果です。今後も使うなら、ランダムに勝ち先読みもないSCORE勢いが第一候補です。高値ブレイクと出来高急増は、タブから外すか条件の見直しが必要です。財務タブの良い成績は、過去の決算データが手に入るまでは確かめられません。

前提と注意点

財務の先読み

ROE・利益率・成長率・自己資本比率・配当は過去の値が無料で取れず、現在の値をさかのぼって当てています。PER・配当利回り・時価総額だけは、その日の株価で計算し直しました。今の決算が良い銘柄を過去に選んでいることになるので、△と×のタブは実際より良く出やすいです。

信用倍率

銘柄別の信用残の過去データが無料で集められないため、信用過多押し目は信用倍率10倍以上の条件を外して検証しました。実際のタブより候補が多い状態の成績です。

SCOREのタブ

SCORE業績・SCORE勢いは、その日のスコア上位10銘柄を買い候補としました。SCORE勢いは株価だけで作れるので先読みはありません。SCORE業績は全項目が財務です。

データ

Yahoo Finance の日足 (調整済み)。現在上場している3,680銘柄のみで、上場廃止銘柄は含みません (生存者バイアス)。株価データの誤りと思われる取引 152 件は除外しました。

売買コスト・税

手数料0円、スプレッドとスリッページは片道 10億円以上 0.10% / 3億円以上 0.15% / 1億円以上 0.25% / 1億円未満 0.40%。数値は税引き前で、利益には年間の損益通算後に20.315%の税がかかります。為替コストはありません。

約定

寄り付きで買えなかった日 (ストップ高・安張り付きなど) は除外。損切り・利確の価格に場中で届いたらその価格、寄り付きで越えていたら始値で約定。同じ日に両方に届いた場合は損切りを先とみなします。
