結論

3つのルールそれぞれで、探索期間に一番良かった条件は直近1年では3つとも日経平均 (+23.3%) を上回りました。一方、探索期間 (日経 年率 +27.3%) と約4年の通し (+26.3%) では、どのルールでもはっきり上回る条件はありませんでした。

  • 損切り-6% / +20%・+40% / 25日: 一番良かったのは「BOS後のディスカウントで押し目」です。探索期間 年率 +27.4% (日経と同じ)、直近1年 +33.0% (DD -13.4%)、通し 年率 +25.6% (日経 +26.3%) でした。日経平均に一番近い成績ですが、1回あたりの期待値は +0.89% / +0.38% と小さめです。
  • 損切り-8% / +20%・+40% / 40日: 前回と同じく CHoCH が一番でした。探索 +20.8%、直近1年 +28.5% (DD -9.6%)、通し +19.9% です。DD が3ルールの中で一番小さい組み合わせです。
  • 損切り-15% / +30%で半分・残りは利確なし / 40日: 探索期間の1位は FVG押し目 (k=2) で、直近1年 +33.4%、通し +21.4% でした。BOS は直近1年 +61.1% と突出していますが、探索期間は +12.9% です。このルールではランダムでも直近1年 +29.9% になるので、上げ相場で利益を伸ばしやすいルールの効果が大きいと見られます。
  • ルールによって勝つ条件が入れ替わる: 1位は、-6%ルールではディスカウント、-8%ルールでは CHoCH、-15%ルールでは FVG でした。どのルールでも安定して上位にいる SMC の条件はありません。SMC 系の中では CHoCH とディスカウントが比較的崩れにくく、オーダーブロックとスイープはルールによって大きくぶれました。

まとめると、直近1年だけなら日経平均を上回る組み合わせがありますが、前半の期間も含めると日経平均とほぼ同じか下回ります。使うなら、DD が小さい「CHoCH × -8% / 40日」か、日経平均に一番近い「ディスカウント押し目 × -6% / 25日」が候補です。

条件の定義 (日足・買いのみ)

スイング高値・安値前後 k 本より高い (安い) 足。右側の k 本が出そろった日に確定とみなす (k は2・3・5本から探索期間で選択)
BOS直近2つのスイング高値・安値が切り上がっている上昇構造のまま、終値が直近のスイング高値をはじめて上抜けた日
CHoCH高値・安値が切り下がっている下降構造だったところで、終値が直近のスイング高値をはじめて上抜けた日
流動性スイープ安値が直近のスイング安値を割り込んだのに、終値はその上に戻した陽線
スイープ → CHoCHスイープから10日以内に CHoCH が出た日
FVG3本の足で1本目の高値 < 3本目の安値 になった空白。BOS から20日以内にできたものに、その後はじめて安値が届き、空白の下端より上で終わった陽線
オーダーブロックBOS の直前にあった最後の陰線の値幅。BOS から20日以内に、はじめて安値が届き、陰線の安値より上で終わった陽線
ディスカウントBOS から30日以内に、BOS 前のスイング安値〜その後の高値 の下半分まで押し、スイング安値は割らずに陽線

前提と注意点

共通の条件

シグナル翌営業日の寄り付きで買い、決算 (推定日) が保有予定期間に入る銘柄は買いません。同時保有は10銘柄、売買代金1億円以上の銘柄だけが対象で、10枠が埋まっているときは売買代金の大きい順に買います。

コスト・データ

売買コストは売買代金に応じて片道0.10〜0.40%、税引き前です。Yahoo Finance の日足 (調整済み) で、上場廃止銘柄は含みません。日経平均は配当なしの指数です。

日足で機械化したもの

SMC・ICT は本来、複数の時間足を見て裁量で判断する手法です。ここでは日足だけで判定できる形にしたため、使う人の見方とは違う場合があります。
